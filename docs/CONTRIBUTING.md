# Follow and contribute

The easiest way to help right now is to follow the project and share general
feedback about what matters to you in a PC version of Mario Tennis.

Please do not send or post game files, ROMs, pictures, sounds, or other copied
game material. The project does not need or accept those files.

The development workspace is private. Public access to the roadmap does not
include access to private development files. The project may invite other kinds
of help later, once there is a safe way to do so.
