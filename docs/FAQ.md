# Frequently asked questions

### What is Italian Plumber Pong?

It is a project that hopes to make Mario Tennis for Nintendo 64 run directly as
a PC game, while keeping the original game experience.

### Is it playable?

No. The project has not reached a running game, title screen or playable match.

### Is this an emulator?

No. The goal is a PC version that runs as a PC game instead of asking players
to open an emulator. That goal has not been reached yet.

### Will it run on Steam Deck or ROG Ally?

Those are goals for the future. Neither device is supported or tested by a
playable build today.

### Will it support four players?

The goal is to keep the original local multiplayer, including four players
where the original game allows it. This has not been tested in a PC version.

### Will it have widescreen?

Widescreen is planned, while keeping the original screen shape as an option. It
does not work yet.

### Will it run at 60 frames per second?

Smooth 60-frame-per-second play is a goal. The project first needs to run the
game correctly, and faster play must not make the tennis move too quickly.

### When will it be released?

There is no release date. The project is still at an early stage.

### Will I need the original game?

The project does not include the game. A future version may ask players to
provide their own compatible game copy. Any such plan will be explained before
there is a playable release.
