# Codex session prompts

This archive contains original session prompts supplied by the project owner, when an authentic copy could be recovered and safely reviewed. Each recovered prompt keeps its original order and wording as much as possible. Sensitive spans are visibly marked instead of being silently rewritten.

The archive is one part of the project story. Read the [development diary](../docs/PROGRESS.md) for plain-English notes about what changed, what it means for players, and what comes next.

## How the prompts are used

The owner chooses priorities and gives a session prompt. ChatGPT helps discuss and plan the work. Codex uses the prompt to investigate, make approved project changes, and report what was verified. The owner and ChatGPT review the results before planning the next step. The diary describes the player-facing progress; these pages preserve the prompts that can be safely shared.

## Authenticity and missing records

A page marked **Authentic** comes from an owner-supplied original prompt. A page marked **Not recovered** means no reliable original prompt was available in the records reviewed. Missing prompts are not reconstructed from reports or memory. An in-progress placeholder does not mean that technical session is finished.

## Visible redactions

Redactions are shown in square brackets, for example `[REDACTED: LOCAL ROM PATH]`, `[REDACTED: PRIVATE ANALYSIS DIRECTORY]`, `[REDACTED: CREDENTIAL]`, `[REDACTED: PERSONAL INFORMATION]`, `[REDACTED: GAME-DERIVED CODE]`, and `[REDACTED: PRIVATE TECHNICAL DETAIL]`. Each item is reviewed in context. Public tool names and ordinary technical ideas may remain when they do not reveal private or game-derived information. A redaction means text was withheld; it does not imply the rest of a prompt is a technical report or a claim that the game works.

The archive does not contain ROMs, game files, extracted material, generated game code, disassembly, private reports, or chat transcripts.
